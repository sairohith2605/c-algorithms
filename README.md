# C algorithms

A collection of algorithm implementations in C. Not just simple ones but also some related to Neural Networks (or Deep Learning in general), for example the Softmax implementation.

> PS: the instructions below have been written by AI, so they should be quite straightforward

## Build and run

Requires a C compiler, Make, and the C math library.

```sh
make
./build/softmax
```

Run `make clean` to remove the files generated by the Makefile. The executable
previously built by hand is preserved at `build/legacy-softmax` and is not
removed by `make clean`.

## Tests

Run `make test` locally or in CI. The first run downloads Unity 2.6.1 into
`build/` and verifies its SHA-256 checksums. It requires `curl`, `sha256sum`,
and network access; subsequent runs can use the cached files. `make clean`
removes the cached Unity files.

## Layout

- `src/`: source files
- `include/`: public headers
- `tests/`: tests
- `docs/`: documentation and design notes
- `lib/`: third-party libraries, if needed
- `build/`: generated objects and executables (ignored by Git)

For clangd, `make` uses the flags in the Makefile. To give clangd the same
flags, install `bear` and run `make clean && bear -- make` to generate a
`compile_commands.json` in the project root.
